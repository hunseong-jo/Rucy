- `UnityEngine.CoreModule.dll`, `UnityEngine.AnimationModule.dll`, `UnityEngine.AudioModule.dll` 등

### 3. 그래픽·렌더링 관련
- `D3D12Core.dll`, `d3d12SDKLayers.dll`

### 5. Mono 런타임
- `MonoPosixHelper.dll`, `mono-2.0-bdwgc.dll`  
  → Unity가 내부적으로 사용하는 Mono 실행 환경이며, 삭제하면 게임이 실행되지 않으니 그대로 두세요.

### 6. 기타

## 권장 정리·최적화 체크리스트
1. **Release 빌드** 사용 → `.pdb` 파일 자동 배제.  
2. **Unused Module 제거** → `Project Settings > Player > Other Settings > Managed Stripping Level` 혹은 **Addressables** 를 통해 실제 사용되지 않는 모듈을 제외.  
3. **플랫폼 전용 라이브러리 확인** → Windows 전용 DLL(`D3D12Core.dll` 등)만 포함하고, 다른 플랫폼용 파일이 섞여 있지 않은지 점검.  
4. **빌드 크기 최적화** → `Editor > Build Settings > Compression Method`를 **LZ4HC**(빠른 압축) 혹은 **LZ4**(압축률)로 설정.  
5. **디버그 로그** → 최종 배포 시 `Player Settings > Other Settings > Development Build`를 해제하고, `Scripting Define Symbols`에서 `DEBUG` 관련 심볼을 제거.

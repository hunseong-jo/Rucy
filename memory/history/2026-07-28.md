## 2️⃣ 모델을 선택하고 스케일 적용 (선택사항)  
Blender는 모델의 스케일이 적용되지 않은 상태(예: `[0.03,0.03,0.03]`) 로 저장돼 있습니다.

2. `Object → Apply → Scale` (단축키 **Ctrl + A → Scale**) 를 실행합니다.  

> *이 작업은 원본 파일을 변경하지 않으므로, 원본을 보관하고 싶다면 “File → Save As…” 로 _수정.blend_ 라는 새 파일명을 지정한 뒤 진행하세요.*

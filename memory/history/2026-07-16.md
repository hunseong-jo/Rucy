현재 사용하시는 **GTX 1650**의 특성(fp32 설정 및 VRAM 제한)상 이미지 생성에 **약 2~5분 정도 소요**될 수 있습니다. 잠시만 기다려 주세요!

```python
import requests
import base64
import os
from PIL import Image
import io

# 설정
WEBUI_URL = "http://127.0.0.1:7860"
DESKTOP_PATH = "C:/Users/user/Desktop/Pill_Agents_Logo.png"

def generate_stomach_icon():
    # 프롬프트: 정면 모습의 깔끔한 위 아이콘, 흰색 라인 아트, 투명 배경 스타일
    prompt = "A minimalist stomach icon, perfectly front-facing, clean white line art, flat vector style, solid black background, high resolution, simple shapes"
    negative_prompt = "checkerboard, grid, shadow, 3d, realistic, human, blurry, text, watermark, green box"

    payload = {
        "prompt": prompt,
        "negative_prompt": negative_prompt,
        "steps": 25,
        "width": 512,
        "height": 512,
        "cfg_scale": 7,
        "sampler_name": "Euler a"
    }

    try:
        print("이미지 생성을 시작합니다... (GTX 1650 fp32 모드 적용 중, 약 2-5분 소요)")
        response = requests.post(f"{WEBUI_URL}/sdapi/v1/txt2img", json=payload)
        
        if response.status_code == 200:
            r = response.json()
            image_data = base64.b64decode(r['images'][0])
            image = Image.open(io.BytesIO(image_data))
            
            # 배경 제거 및 PNG 변환 (단순화된 방식: 검은색 배경을 투명으로)
            image = image.convert("RGBA")
            datas = image.getdata()
            
            newData = []
            for item in datas:
                # 검은색에 가까운 배경을 투명하게 처리
                if item[0] < 30 and item[1] < 30 and item[2] < 30:
                    newData.append((255, 255, 255, 0))
                else:
                    newData.append(item)
            
            image.putdata(newData)
            image.save(DESKTOP_PATH, "PNG")
            print(f"성공! 이미지가 바탕화면에 저장되었습니다: {DESKTOP_PATH}")
            return True
        else:
            print("WebUI 응답 오류입니다.")
            return False
    except Exception as e:
        print(f"연결 실패: WebUI가 켜져 있는지 확인해 주세요. (D:\\stable-diffusion-webui\\webui-user.bat)")
        return False

generate_stomach_icon()
```

### 2️⃣ 스크립트·명령어로 자동 조절하기  

#### (a) PowerShell + `nircmd` (무료 유틸)  
1. `nircmd.exe` 를 <https://www.nirsoft.net/utils/nircmd.html> 에서 다운로드 후 `C:\Windows\` 혹은 원하는 폴더에 놓습니다.  
2. 아래 PowerShell 명령을 실행하면 시스템 볼륨을 **30 %** 로 조절할 수 있습니다.

```powershell
# 30% (전체 65535 중 0.3 비율)
C:\Windows\nircmd.exe setsysvolume 19660
```

- **볼륨을 0 % 로 내리고 싶다면** `setsysvolume 0`  
- **볼륨을 100 % 로 올리고 싶다면** `setsysvolume 65535`

#### (b) Python + `pycaw` (Windows 전용 라이브러리)  
```python
import comtypes
from comtypes import CLSCTX_ALL
from pycaw.pycaw import AudioUtilities, IAudioEndpointVolume

comtypes.CoInitialize()                      # COM 초기화
devices = AudioUtilities.GetSpeakers()
interface = devices.Activate(IAudioEndpointVolume._iid_, CLSCTX_ALL, None)
volume = interface.QueryInterface(IAudioEndpointVolume)

# 0.0 ~ 1.0 사이 값 (0.3 = 30%)
volume.SetMasterVolumeLevelScalar(0.3, None)
print("볼륨을 30% 로 설정했습니다.")
```

- 위 코드를 실행하려면 `pip install pycaw comtypes` 로 패키지를 먼저 설치해야 합니다.  
- 실행 전 **Python 환경이 관리자 권한으로 실행**돼 있어야 정상 동작합니다.

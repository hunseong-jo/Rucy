  - **눈 실측(직접 호출로 확인, 추측 금지)**: **Groq qwen3.6-27b(주력) 0.7초 ✅**, Gemini 계열 ✅, Groq llama-4-scout 0.2초 ✅ / **Cerebras·Groq qwen3-32b·OpenRouter·로컬 qwen3:4b는 눈 없음 ❌**. → config에 `"vision": true` 플래그, 라우터가 이미지 요청이면 그 모델들만 고름. (bench.apply가 모델 블록을 통째로 보존해 플래그는 /벤치 후에도 살아남음)
  - ⚠️**함정1**: 이미지가 실린 요청에 **도구 명세까지 실으면 거절**하는 모델이 있음 → 보는 턴은 `use_tools=False`. 감수(review)도 끔 — **감수자는 그림을 못 보므로 맞는 답을 엉뚱하게 '고침'**.
  - ⚠️**함정2(테스트가 잡아낸 실제 버그)**: 이미지 메시지를 대화에 남기면, **그림을 보여준 다음 글로만 묻는 턴**에서 눈 없는 모델이 전부 `content must be a string` 400·403으로 거절(Cerebras 403은 키 문제가 아니라 이것). → **이미지는 딱 한 턴만 살고 매 턴 시작에 자리표시자로 치환**. base64 수 MB 재전송으로 토큰 한도 태우는 것도 같이 막힘. 후속 질문("이 그림에서 ~는?")은 `refers_back()`으로 직전 이미지를 자동 재첨부.
- **실수 노트(`lessons.py`, `memory/lessons.md`)** — 루시는 자기가 틀렸는지 모름 → **신호는 사용자의 지적**(`is_correction`: 틀렸/아니야/잘못…, 단 "내가 잘못 눌렀어"는 제외). 지적 감지 시 직전 문답+지적+고친 답을 모델이 한 줄 교훈으로 뽑아 저장, 다음 유사 질문에 임베딩으로 찾아 주입. **답을 다 내보낸 뒤에 적어서 사용자를 기다리게 하지 않음.**
  - 통 분리 원칙 유지: notes.md=개인 사실 / knowledge/=프로젝트 지식 / **lessons.md=행동 지침**. 섞으면 검색 공간이 흐려짐.
  - `min_score` 0.55로 기억 검색(0.45)보다 **높게** — 관련 낮은 교훈이 딸려오면 매 질문에 엉뚱한 잔소리가 붙음. 중복은 임베딩 0.90으로 차단. 모델이 "교훈감 아님"이라 판단하면 안 적음(빈 노트 > 오염된 노트). `/교훈`·`/교훈 삭제 <말>`.

⭐**핵심은 검증이다.** 모델은 "다 했습니다"라고 말하는 데 아무 저항이 없다 — **E2E 1회차에서 파일을 하나도 안 만들어 놓고 "생성했습니다"라고 보고했고, 있지도 않은 2023년 시각까지 지어냈다.** 그래서 단계마다 **별도 턴**의 검사관이 도구가 돌려준 근거(tool 메시지)와 대조해 완료를 판정하고, 아니면 이유를 알려주며 다시 시킨다.

### v2.1 — 코어 해치 재설계 (사용자 "배 부분 큐브 파츠가 어색")
🚨⭐**직사각 패치는 유기체 위에서 '큐브 파츠'로 읽힌다.** 해법 = **잎사귀 윤곽**(경첩변만 직선, 자유변은 `sqrt(1-(2u-1)²)` 타원 마스크) + **가장자리로 갈수록 얇아지는 렌즈 단면**(두께를 마스크·경첩거리에 비례) + 회색 판 재질을 살색 계열로. 삼각형 23,748. 껍데기가 살덮개처럼 벗겨지는 형태가 됨.

### v2.2 — 입술 겹침 수정 + 촉수 추가 (사용자 지적)
- 🐞**입술 덩어리 9개가 이빨과 겹친 원인 = 같은 반경대**(입술 1.44 / 이빨1열 1.30 / 엄니 1.34). **반경이 아니라 깊이(s)로 분리해야 함** → 입술을 입 뒤 `s=0.62` 목덜미로 물려 살목도리로. ⭐부위끼리 겹치면 '크기'가 아니라 '어느 축으로 분리돼 있는가'를 볼 것.
- **촉수 추가**(사용자 요청 "가느다란 촉수를 달고 다니는 디자인"): 입 둘레 10가닥(길이 1.5~2.6m, 입술 사이에서 나옴) + 몸통 좌우 옆구리 18가닥. 끝으로 갈수록 가늘어지는 휜 관(`tentacle()` 헬퍼, 6각 링). **26,884tri.**
- 🐞`a = sgn*118°`는 좌우가 아니라 **같은 쪽의 위아래**가 된다(cos 부호가 둘 다 음수) → `-38°/-142°`로. 단서는 높이가 4.6→6.3으로 튄 것.
- 촉수가 바닥을 뚫어서 warp 후 `z=max(z,0.035)` 클램프 → 눌려 끌리는 모습이 됨.
- 미리보기 = 자세 2종 × 컷 6종(전신/측면/스케일/입/코어/흡반). ⭐**카메라를 눈대중으로 두지 말고 부위 실제 좌표에서 계산할 것**(프록시가 프레임 밖으로 밀린 사고 반복).

### v2.5 — 매미 날개 삭제 + 질감(절차 셰이더). **34,284tri**
- 사용자 지시로 **날개 삭제**. ⚠**날개가 코어 덮개 역할이었음 — 지금은 코어가 상시 노출.** 덮개는 나중에 소켓 살이 조여드는 방식으로 다시 잡기로.
- 🚨🚨**중대 버그 발견·수정: 흡반·가스낭·코어 블록이 통째로 복제돼 있었다.** 원인 = 날개 패치 때 `s[:a] + new + s[b:]`에서 **b 마커가 a보다 앞에 있었음**(코어 블록이 흡반보다 뒤인 걸 잘못 봄) → 중간 구간이 두 번 들어감. **좌표가 같아 렌더로는 전혀 안 보이고 삼각형만 먹었다**(42,956 → 정리 후 34,284). ⭐**슬라이스로 코드 블록을 갈아끼울 땐 `assert a < b`를 반드시 넣을 것.**

- 🐞**보로노이 경계를 그대로 쓰면 전신이 '갈라진 진흙'이 된다** → 선 폭 0.09→0.045 + **큰 노이즈로 마스킹해 군데군데 뭉쳐 나게** + 세기 0.72배. 근접에서는 젖은 조직, 원거리에서는 매끈하게 읽힘.
- 조명에 뒤에서 훑는 림라이트 추가, 샘플 40→96.

### v2.6 — 때(grime) 추가 (사용자 "질감이 리얼한데 너무 깨끗하다")
⭐**'너무 깨끗하다'의 정체 = 표면이 형태와 무관하게 균일한 것.** 노이즈를 아무리 더해도 안 풀리고, **파인 곳에 때가 앉아야** 해결된다.
- 🔑**cavity를 정점 컬러로 구워서** 해결: 주름을 뺀 민짜 프로파일 `Rbase(s)`를 기준선으로 `(Rbase-반경)/(Rbase*0.22)`를 정점마다 계산 → `color_attributes`("cavity") → 셰이더에서 Vertex Color 노드로 읽어 골·소켓에 어두운 때. **EEVEE에서 Pointiness/AO 노드를 못 믿을 때 쓰는 확실한 방법.**
- 얼룩 3종 추가: ①소화액 누런 반점(노이즈 1.05 샤프 램프) ②**흘러내린 자국**(Mapping으로 Z축만 0.55배 늘인 노이즈) ③이물질 잔 점(보로노이 90). 얼룩 낀 곳은 roughness도 함께 올려 '마른 때'로.

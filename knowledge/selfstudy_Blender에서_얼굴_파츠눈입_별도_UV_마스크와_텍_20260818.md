# Blender에서 얼굴 파츠(눈·입) 별도 UV 마스크와 텍스처 베이킹을 이용한 정밀 텍스처링 워크플로우 — 루시 자가 학습 노트 (2026-08-18)

> 루시가 스스로 웹을 조사해 정리한 노트입니다. 검증되지 않았을 수 있으니
> 수치·사실을 인용할 때는 출처를 함께 말할 것.

## 목표  
- 얼굴 파츠(눈·입)를 별도 UV 마스크로 구분하고, 텍스처 베이킹으로 정밀한 디테일을 획득한다.  

## 핵심 워크플로우  

| 단계 | 핵심 내용 | 출처 |
|------|-----------|------|
| **1. 모델 준비** | 얼굴 메시에 눈·입 등 파츠별 **Island**(섬) 를 명확히 구분한다. | 【3】https://arca.live/b/3d3d/101668980 |
| **2. UV 언래핑** | *UV 매핑 기초* – **Seam**을 적절히 배치하고 **Unwrap**한다. 파츠별 Island 를 개별 UV 영역에 배치해 서로 겹치지 않게 한다. | 【1】https://devorangee.tistory.com/25 |
| **3. 별도 UV 마스크 생성** | 파츠별 **UV Selection**(얼굴 파츠 선택) → **UV → Hide/Show** 로 마스크를 만든 뒤, **Vertex Paint** 혹은 **Image Editor** 에서 마스크 이미지를 저장한다. (UV 마스크는 별도 이미지 파일로 내보낼 수 있다.) | 【3】https://arca.live/b/3d3d/101668980 |
| **4. 텍스처 베이킹 설정** | *베이킹 대상* – Diffuse, Normal, Ambient Occlusion 등. <br>• **Bake Type** 선택 후 **Margin**(여백)값을 충분히 설정한다. <br>• **Cage** 를 사용하거나 **Ray Distance** 를 조정해 레이‑오버플로 오류를 방지한다. | 【2】https://arca.live/b/3d3d/101991163 |
| **5. 파츠별 베이킹** | 눈·입 각각 **UV 마스크**를 활성화한 뒤 **Bake**를 실행한다. 이렇게 하면 다른 파츠의 정보가 섞이지 않는다. | 【2】https://arca.live/b/3d3d/101991163 |
| **6. 베이킹 오류 대처** | - **"Ray Length too short"** → Cage 혹은 Ray Distance 증가.<br>- **"Missing images"** → 베이킹 전 이미지 노드가 연결돼 있는지 확인.<br>- **AO 베이킹** 시 **Bias** 값을 조정해 그림자 아티팩트 억제. | 【2】https://arca.live/b/3d3d/101991163 |
| **7. 최종 합성** | 파츠별 베이킹 결과를 **Image Editor** 에서 레이어(눈, 입)로 합치고, 필요 시 **Blend Mode**(Multiply, Overlay 등) 로 미세 조정한다. | 【1】https://devorangee.tistory.com/25 |

## 유의사항 & 충돌 여부  
- 세 출처 모두 **UV 매핑**과 **텍스처 베이킹**에 대한 기본·실전 정보는 일관되게 제시한다. <br>‑ 다만, **별도 UV 마스크**를 “이미지로 저장”한다는 구체적 설명은 출처 3에만 암시적으로 존재한다(섬 선택·숨기기 기능). 다른 출처에서는 해당 절차가 명시되지 않아 **추가적인 상세 단계**는 제공되지 않는다.  
- **베이킹 오류**와 해결법은 출처 2에 한정되어 있다. 다른 두 출처에서는 오류 처리에 대한 언급이 없으므로, 오류 대처 내용은 출처 2에만 근거한다.  

## 핵심 팁 요약  
- **Island 별도 배치** → 파츠 마스크 제작의 전제.  
- **UV 마스크 활성화** 후 베이킹 = 파츠별 노이즈·섞임 최소화.  
- **Margin + Cage** 설정은 베이킹 아티팩트 방지 핵심.  
- 오류 발생 시 **Ray Distance**·**Bias** 조정이 가장 빠른 해결책.

→ 데이터 독점 + 서비스 직접 제공 = 프리미엄 경험의 원천

### [9주차] p8
Part 01 |
전문가 분석: 폐쇄형 루프의 전략적 가치
왜 아멕스만 '직접 발급 + 직접 네트워크'를 고집하는가?
아멕스의 폐쇄형 루프(Closed Loop) 모델은 가맹점 수는 적지만, 데이터 독점과 서비스 품질에서 압도적 우위를 가집니다. 이것이 프리미엄 포지셔닝과
콘텐츠 마케팅의 원천입니다.
비교 항목 폐쇄형 (아멕스) 개방형 (Visa/MC)
카드 발급 아멕스가 직접 발급·관리 제휴 은행이 발급 (국민·신한 등)
결제 네트워크 아멕스 자체 네트워크 Visa/MC 네트워크
데이터 소유 거래 데이터 100% 직접 보유 은행과 네트워크가 분산 보유
가맹점 수 약 700만 (상대적으로 적음) 약 1억+ (전 세계 최대)
가맹점 수수료 높음 (2.5~3.5%) → 높은 수익 낮음 (1.5~2%) → 박리다매
서비스 품질 직접 관리 → 일관된 프리미엄 경험 은행별 차이 → 품질 편차 큼
마케팅 데이터 최강 (고객 전체 여정 파악 가능) 제한적 (네트워크 데이터만)
디지털 마케팅 관점의 핵심 인사이트
폐쇄형 루프 = 데이터 독점 → 개인화 마케팅의 정확도가 개방형 대비 월등. 아멕스가 'Amex Offers'로 위치 기반 실시간 할인을 제공할 수 있는 이유.
가맹점은 적지만, '프리미엄 고객이 많이 쓰는 가맹점'에 집중 → 프리미엄 제휴(항공·호텔·레스토랑) 협상력 극대화.

1. 산업이 다르면 전략이 달라야 한다: 제조·이커머스·금융·프리미엄 금융은 규제·고객·데이터가 근본적으로 다름

3. 데이터가 개인화의 깊이를 결정한다: 관심사(삼성) < 구매(쿠팡) < 결제(KB) < 전체 거래(아멕스)

# 블렌더·유니티 모바일 3D 에셋 기준표 (세션63 3부, 2026-07-18)

루시가 3D 에셋 수치를 판정할 때 대는 자. **blender_3d의 info·check·수술 결과가 이 기준과
자동 대조해 📏 경고를 붙인다** — 여기 수치를 바꾸려면 config의 `blender.budgets`를 쓰면 되고
(코드 수정 불필요), 이 문서는 근거와 예외를 기록하는 유일 원본이다.

## 폴리곤(삼각형 기준 — 유니티·GPU는 전부 삼각형으로 셈)

| 대상 | 기준(삼각형) | 근거 |
|---|---|---|
| 배경 소품(돌·울타리·상자) | 500~2,000 | 화면에 수십 개씩 깔림 |
| 주요 소품(무기·가구·기계) | **5,000 이하** ← 자동 경고 기준 `prop_tris` | 클로즈업 있어도 이 선 |
| 일반 캐릭터·생물 | 8,000~15,000 | 동시 여러 마리 |
| 주인공급 캐릭터 | **30,000 이하** ← 자동 경고 기준 `char_tris` | 화면에 1~2개만 |

- 블렌더 '폴리곤 수'는 면(쿼드=1) 기준이라 삼각형은 대략 2배 — 루시 info는 **삼각형을 정확히
  따로 세서**(total_tris) 대조하고, 수술 결과는 면×2 추정으로 대조한다("약" 표기).
- 넘었을 때 처방: `decimate`(비율 감폴리) → 디테일 아쉬우면 `bake`(노멀 굽기)와 세트,
  화면 멀리 있는 것은 `lod`.

## 재질·드로우콜

- 파일 전체 재질 **8종 이하**(자동 경고 기준 `materials`). 오브젝트 하나엔 1~2종이 이상.
- 근거: 모바일에서 재질 1종 ≈ 드로우콜 1개. 수십 개면 발열·프레임 하락.
- 처방: `materials`(중복 병합) → 더 줄이려면 `uv_atlas`(여러 재질을 텍스처 한 장으로 굽기).

## 텍스처

- 소품 1024px, 주인공급 2048px까지. 초과분은 `tex_resize`(블렌더 쪽)·`unity_tex_fix`(유니티 쪽).
- ⚠️크기보다 급한 것: **이름 ASCII**(한글·공백=유니티에서 텍스처 실종 → `rename`·`unity_export`가 처리)
  와 **외부 파일 방식**(FBX+PNG 같은 폴더 — 임베드는 URP에서 안 물림, 세션58 실측).

## 본(뼈)

- 캐릭터당 **75개 이하**(자동 경고 기준 `bones`). 유니티 모바일 스키닝은 본이 많을수록 비싸고,
  bone_template 표준(휴머노이드 17본·네발 15본)이면 넉넉히 안쪽.
- 본당 정점 영향(스킨 웨이트)은 유니티 Quality의 Skin Weights 2~4와 짝 — 웨이트는
  auto_weight/weight_transfer가 알아서 4개 이하로 만든다.

## 예외 (경고를 무시해도 되는 경우)

- 기획서용 렌더·컨셉 확인용 파일(게임에 안 들어감) — beauty_render 대상은 예산 무관.
- 베이크 소스용 하이폴리(`bake`의 high) — 애초에 게임에 안 나가는 원본.
- PC 전용 빌드를 따로 뽑는 경우(샐러드팜은 모바일 전용이라 해당 없음).

## 루시 자동 대조가 걸리는 곳

- `blender_3d info` — 삼각형(캐릭터/소품 자동 판별: 뼈대 있으면 캐릭터 기준)·재질 수·본 수.
- `blender_3d check` — 반입 점검에 삼각형 예산 줄 추가.
- 폴리를 바꾸는 수술(bevel·solidify·decimate·boolean·mirror·curve_path) — 결과가 예산을 넘으면 📏 한 줄.
- 기준 변경: config `blender.budgets`에 `prop_tris`/`char_tris`/`materials`/`bones`.

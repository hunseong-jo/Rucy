**구조(3겹)**: 유리 돔(PillGlass, alpha 0.32, 뒷면컬링 ON) → 얼굴 디스플레이(FaceScreen, 표면에서 0.025 안쪽)
→ 내부 셸(PillInner, 0.045 안쪽 = 돔 면 복제 후 정점 노멀 방향으로 밀기). 슬롯 5개, 4,620 tris.

⭐**최대 함정: "투명 유리"는 뒤에 어두운 것이 있어야만 성립**. 뒷면 컬링을 켜면 돔 안이 비어
배경이 그대로 비쳐 들어와 ①빨강이 분홍으로 탈색 ②검은 디스플레이가 안 검음. 해결 = 내부 셸 추가.
그리고 **내부 셸은 어둡게가 아니라 '밝은 팩 색'**이라야 검은 판과 대비가 생김(어둡게 하면 둘 다 뭉개짐).
내부 셸 inset을 크게(0.07) 잡으면 정수리에 셸이 안 닿아 창백한 띠가 생김 → 0.045.

⭐**아틀라스 칸 비율 = 디스플레이 판 비율**이어야 함. 판이 2:1인데 칸이 정사각이면 얼굴이 가로로 늘어남
(눈이 납작해짐). 아틀라스 1024x512 / 칸 256x128, 판도 정확히 2:1(FX 0.272, 높이 0.272)로 맞춤.
그리기 좌표계는 '세로 높이 단위'(x∈[0,2], y∈[0,1])로 통일하면 x/y 픽셀 배율이 같아져 왜곡이 사라짐.

⭐**FBX 익스포터는 Base Color에 물린 이미지만 텍스처로 실어보냄**. Emission Color에만 연결하면
FBX 텍스처 참조가 **빈 채로 나가서** 유니티에서 얼굴이 안 나옴(bar 갈색 함정과 같은 계열).
→ 아틀라스를 Base Color에도 같이 연결. 그리고 blend 저장 시 auto-pack 되므로 수출 직전
`img.save() + img.unpack(REMOVE) + filepath 재지정`으로 외부화. path_mode는 **STRIP**
(COPY는 .fbm 하위폴더를 만들어 납품이 지저분함 — [[fbx-inspect-s59]] 참조).

**이모트 방식(사용자 선택)**: UV 아틀라스 오프셋. 4x4=16종, Tiling (0.25,0.25), Wrap **Clamp**(옆 칸 샘). 
유니티는 `mainTextureOffset` + **`_EmissionMap` 오프셋을 반드시 같이** 이동(안 그러면 모양과 빛이 어긋남).
v = (3 - idx/4)*0.25 — UV 원점이 좌하단이라 행 반전 필요.
**색상 팩 4종은 텍스처 없이 머티리얼 색만**(아틀라스는 흰 도형/검은 배경 마스크 → Emission Color로 틴트).

**표정 그림 주의**: 판이 둥근 사각이라 칸 네 귀퉁이는 잘림 → 장식(zzz·땀방울)을 가장자리에 두면
안 보이거나 눈과 겹침. 안전영역 = 가로 80% / 세로 85%. 화남/슬픔 눈썹은 **안쪽 끝 방향**이 정반대
(화남=안쪽 내려감 \ /, 슬픔=안쪽 올라감 / \) — PIL은 y가 아래로 증가하니 부호 헷갈리기 쉬움. 실제로 한 번 뒤집혀 나옴.

**Blender 5.0**: `blend_method` 없어짐 → `surface_render_method`('BLENDED'/'DITHERED'), hasattr 분기 필요.
`Material.use_nodes`는 6.0에서 제거 예정 경고.

  (전형적인 LBS candy-wrapper). 각도를 줄이는 건 미봉책이었음.
- ⭐**해법: 몸 전체 회전을 웨이트가 없는 `Root` 본으로 옮긴다.** Root 는 모든 정점의 부모라
  **모든 정점이 완전히 같은 변환**을 받아 변형이 원천적으로 0. 넘어짐·상체 기울기 전부 Root 로 이관하고
  Hips/Spine/Head 로컬 회전은 None 으로 비웠다. 결과: 점프 8프레임·기절 전 구간 이음매 한 줄로 깨끗.
- **Root 규약**: X+ = 뒤로 넘어짐(피벗이 발밑 z=−0.567 이라 넘어지는 축으로 딱 맞음), 로컬 Z = 월드 Z 그대로.
  ⚠Hips 는 X+ 가 앞이라 **Root 로 옮길 때 부호를 뒤집어야 한다.**
  ⚠**Root 를 회전시키면 Hips 의 로컬 이동축도 함께 돌아간다** → 눕는 동작의 높이 보정도 Root 로 옮길 것.
  바닥 보정 스크립트도 Root(로컬 Z=index2) / Hips(로컬 Y=index1) 양쪽을 찾도록 고침.

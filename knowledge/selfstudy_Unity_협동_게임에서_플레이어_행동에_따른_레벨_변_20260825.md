# Unity 협동 게임에서 플레이어 행동에 따른 레벨 변형(다이나믹 레벨) 설계 및 구현 방법 — 루시 자가 학습 노트 (2026-08-25)

> 수치·사실을 인용할 때는 출처를 함께 말할 것.

## 핵심 내용 정리  

### 1. 플레이어 행동 기반 레벨 변형의 기본 흐름  
- **실시간 플레이어 분류**를 위해 Unity와 Transformer 모델을 연동한 시스템을 설계·구현한다.  
- 가장 널리 사용되는 **군집 분석(클러스터링)** 기법을 적용해 플레이어 행동 유형을 실시간으로 구분한다. [출처 1]  

### 2. 동적 레벨 구현 방법  
- Unity에서는 **각 레벨을 별개의 씬(Scene)** 으로 관리한다.  
- 플레이어 행동에 따라 현재 씬을 유지하거나, 다른 씬으로 전환해 레벨을 변형한다. [출처 2]  

### 3. 레벨 디자인 기본 개념(Unity 공식 자료)  
- Unity는 **레벨 디자인 전반**을 다루는 가이드를 제공한다.  
- 여기에는 **지형(Terrain), 네비게이션, 조명, 오브젝트 배치** 등 레벨을 구성하는 주요 요소에 대한 소개가 포함된다. [출처 3]  

### 4. 구현 시 고려사항  
- **플레이어 분류 → 클러스터링 결과**를 트리거로 활용해 씬 전환 또는 씬 내부 요소(예: 적 배치, 난이도) 변화를 유발한다.  
- 씬 전환 시 **로드 최적화**와 **데이터 동기화**가 필요하지만, 구체적인 방법은 출처에 언급되지 않는다.

## 학습 노트: Unity ModelImporter 및 3D 모델 임포트

**조사 개요**
제공된 자료는 Unity 매뉴얼의 네비게이션 구조와 웹페이지 헤더 정보를 포함하고 있으나, `ModelImporter` 클래스의 구체적인 속성, 메소드, 또는 자동화 코드 예제에 대한 실질적인 내용은 담겨 있지 않음.

**주요 확인 사항**
*   **문서 범위 및 버전**
    *   '모델 임포트 설정 창'과 '모델 임포트' 관련 문서가 Unity 5.6부터 2023.2 버전까지 존재함.
    *   해당 페이지는 지원되는 버전(Supported)과 레거시 매뉴얼(Legacy Manual)로 구분됨.
*   **URL 및 파일 명 분석**
    *   '모델 임포트 설정 창' 문서의 URL 경로에는 `class-FBXImporter.html`이 포함됨.
    *   '모델 임포트' 문서의 URL 경로에는 `ImportingModelFiles.html`이 포함됨.
*   **외부 참고 자료**
    *   Reddit(r/unity)에 '유니티에 3D 모델 어떻게 임포트해요?'라는 제목의 게시글이 존재함.
    *   단, 해당 링크의 본문 내용은 "Please wait for verification" 상태로, 구체적인 정보가 확인되지 않음.

**데이터 분석 결과**
현재 자료로는 `ModelImporter` 클래스를 활용한 정밀 분석 방법이나 설정 자동화 절차를 도출할 수 없음. 기술적인 세부 사항은 문서 본문 내의 스크립팅 API 섹션 참조 필요.

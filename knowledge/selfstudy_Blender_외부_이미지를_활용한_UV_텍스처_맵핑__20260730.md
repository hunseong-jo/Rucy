# Blender 외부 이미지를 활용한 UV 텍스처 맵핑 및 머터리얼 설정 학습 노트

## 1. 텍스처 이미지 활용 개요
*   **사용 이미지:** JPG, PNG, PSD 등 비트맵 이미지를 활용한다.
*   **기법:** 오브젝트의 표면에 색상을 입히는 대신 이미지를 사용하여 채우는 방식이다.
*   **자료 확보:** 직접 제작하거나 재질 이미지를 제공하는 사이트(Textures.com 등)의 파일을 활용할 수 있다.

## 2. UV 맵 작업 공간 설정
*   **목표:** 원하는 면에 원하는 이미지를 재질로 활용하기 위해 UV를 펼치는 과정이다.
*   **진행 순서:**
    1.  기본 Layout 작업공간에서 오브젝트를 선택한다.
    2.  Edit Mode(편집 모드)로 진입한다.
    3.  상단의 Layout 작업공간을 **UV Map**으로 변환시킨다.
*   **화면 구성:** 이 과정을 거쳐야 양쪽으로 구분된 UV 편집용 레이아웃을 만날 수 있다.
*   **확인:** 왼쪽 화면에서 전체(A) 선택된 면이 펼쳐진 맵을 볼 수 있다.

## 3. 복잡한 UV 재구성 (Mark Seam)
*   복잡한 UV를 다시 펼치기 위해 기준이 되는 엣지(Edge)를 지정해야 한다.
*   **방법:**
    1.  기준 엣지를 선택한다.
    2.  단축키 **Ctrl + E**를 누른다.
    3.  메뉴에서 **Mark Seam**을 선택하여 지정한다.
*   해당 마크를 기준으로 UV를 재구성하는 방법은 추가 튜토리얼을 참고하는 것이 좋다.

## 4. 텍스처 파일 관리
*   텍스처 이미지 파일명이 헷갈리지 않도록, 기존 파일명 뒤에 **'color'**를 붙여서 만드는 것을 권장한다.
*   **예시:** `top turtlenec...` (뒤에 color 추가)

## 출처 및 충돌 사항

*   **제공된 URL:** https://docs.zepeto.me/studio-guide-kr/dmhv-uv
*   **주의 사항:** 제공된 조사 자료의 내용(블렌더 튜토리얼)과 하단에 기재된 URL(제페토 스튜디오 가이드)이 서로 일치하지 않는다. 본문은 블렌터 내용을 기준으로 작성되었다.

# 생물 이미지 반입 시 표준 파이프라인 (2026-07-07 사용자 지시)

사용자가 생물 도트 이미지를 가져오면 **묻지 말고 아래 4가지를 한 세트로** 처리한다.

1. **이미지 적용** — 진화(stage2)면 `CreaturesEvolved2/<기본스프라이트명>.png`, 시크릿 등 진화 없는 종이면 기본 스프라이트 교체(PNG만 덮어써 guid 보존). 셀 자동감지→128 변환, meta는 bd3 규격 복제+새 guid.
2. **자는 모습 생성** — v3 스타일(승인 템플릿 아치+가로 미러 질감 채움, [[todo-evolved-sleep-face-fix]]). 눈 색 어두우면 dark_max 조정.
3. **이동 프레임 생성** — 기본=걷기(1px 바운스+발 교차+꼬리 있으면 꼬리 바운스), 날개면 날개짓, 부유면 파티클 반짝임(CreaturesWalk/). 생물 특성에 맞게.
4. **발/방향 확인** — 수치로: 발끝 오프셋(발목vs발끝 중심, +=우향), 꼬리/덩굴 위치(꼬리 오른쪽=좌향). **아트는 우향이 정상**(flipX=dx<0). 좌향이면 전 파일 미러.

**Why**: 세션30에서 이 흐름이 확립됨(오판·이중미러 사고 겪으며 검증법 정착). 사용자가 매번 다시 설명하지 않도록 표준화 요청.
**How to apply**: 파이프라인 상세·함정은 [[feature-creature-evolution]] 세션30 절 참고. 스크립트는 스크래치패드 소멸 가능 → 메모 기준 재작성.

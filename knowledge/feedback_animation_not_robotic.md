# 애니메이션은 대칭 키프레임으로 만들면 로봇이 된다 (2026-07-15)

알약 요원 걷기 사이클(2포즈+지나침, 전 관절 동시 극점)에 사용자 피드백: **"너무 어색해. 로봇 같애. 걷는 느낌이 없어. 다음부턴 이걸 조정해서 작업해줘."**

**Why:** 디딤/지나침 2포즈에 모든 본이 같은 프레임에서 극점에 도달하고, 무릎·무게이동·오버랩이 없어서 기계 왕복운동으로 보였음. 수학적으로 깔끔한 사이클 = 생명감 없음.

**How to apply(다음 애니 작업 체크리스트):**
1. **무릎(정강이 본) 필수** — 다리 1본 스윙은 무조건 로봇. 스윙 다리는 접고, 디딘 다리는 펴짐.
2. **4포즈 워크사이클**: Contact(디딤) → Down(최저점 — 디딤 **직후** 1~3프레임 뒤, 무릎 눌림) → Passing(최고점) → Up(밀어올림). 최저점을 디딤과 같은 프레임에 두면 무게가 없다.
3. **오버랩/팔로스루**: 팔 키를 다리보다 1~2프레임 늦게, 손목은 팔보다 더 늦게. 극점 도달 프레임을 관절마다 어긋나게.
4. **무게 이동**: 디딘 발 쪽으로 몸통 X 이동+기울기(좌우 sway), 골반 대응 회전이 있으면 상체는 반대로 살짝.
5. **접지감**: 디딘 발은 등속으로 천천히 뒤로(바닥에 붙은 느낌), 허공 발은 빠르게 앞으로(타이밍 비대칭). 착지에 스쿼시(몸 살짝 눌림).
6. 검증은 GIF로 — 정지 프레임 3장으로는 어색함이 안 보인다(이번에 프레임 검수는 통과했지만 움직임은 어색했음).

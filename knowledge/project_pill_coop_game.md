**알약 협동 게임 기획 (가칭, 2026-07-08 첫 논의)**

플랫폼/기술: **Unity 3D** (샐러드팜의 2D 도트와 달리 3D. 멀티플레이 네트워킹 솔루션 미정 — NGO/Photon/Mirror 등).

**역할 분담: 개발은 다른 인원이 담당, 사용자는 기획서 작성만.** → 이 프로젝트에서 내 일은 코드가 아니라 기획서(개발자 핸드오프용 스펙 문서) 작업 지원.

**기획서 초안 v0.1 생성 완료 (2026-07-08)**: `Desktop\알약협동게임_기획서_초안_v0.1.pptx`, 16장, python-pptx 생성+COM 이미지 검수 통과. 구성: 표지/개요/플로우/사이즈 시스템(수치)/나눠주기·부활/도구4종 스펙/배분·스왑/적/맵·위산파도/임무3종/인트로/엔딩·등급/바리에이션/예외규칙 Q&A/개발 우선순위(MVP 3단계)/미확정 리스트. 모든 수치는 초안 딱지. 생성 스크립트는 스크래치패드(세션 종료 시 소실)라 수정 시 pptx 직접 편집 또는 재생성.

핵심 규칙:
1. 2~4인 협동. 플레이어=알약 속 요원.
2. 소화제 도구 4종을 각자 골라 협동: 가스 제거(광선총) / 위산 중화(구형 방어막) / 소화 효소(음식물 부수는 드릴) / 진통(힐).
3. 시간이 지날수록 사이즈 감소 = 체력이자 타이머. 일정 이하로 줄면 행동불능, 사이즈 클수록 도구 위력↑.
4. 부활: 팀원이 자기 사이즈를 나눠줘서 기절자 사이즈 회복(생명력 나눠주기).
5. 맵(위) 곳곳의 사이즈 유지 아이템으로 버팀.
6. 적: 가스 뭉치, 박테리아 등.
7. 인트로: 식도 통과 — 좌우 이동 균형 잡으며 장애물 피해 위까지 하강.
8. 레벨 바리에이션: 매운 음식(마라탕) 위, 과음한 위 등 '먹은 것'에 따라 스테이지 변주.
9. 인원별 도구 배분(확정): 2인=2개씩 들고 스왑, 4인=1개씩(3인=한 명 2개 식으로 자연 확장). 제안 얹음: 스왑에 1~2초 홀스터 딜레이를 둬서 2인 플레이의 판단 긴장감 유지.

**엔딩(확정, 사용자 안)**: 도전과제 전부 달성 → 사이렌+본부 방송("임무를 완수하였습니다. 빠른 시간 내에 탈출구로 향하세요") → 회오리 물살을 거슬러 출구까지 상승 탈출. 인트로(식도 하강)와 거울 구조. 제안 얹음: 가스 기포 타고 상승(적→발판 반전)·트림 사출 코믹 마무리·회오리에서 사이즈 나눠주기로 전원 탈출→엔딩 등급.

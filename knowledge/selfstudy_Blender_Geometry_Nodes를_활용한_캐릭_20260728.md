# Blender Geometry Nodes 캐릭터 털(Fur) 제작 파이프라인 학습 노트

## 1. 프로시저털 털 제작 기초 (Blender Studio)
- **트레이닝 코스**: 'Geometry Nodes from Scratch' 강의의 일부로 구성됨.
- **소프트웨어 버전**: Blender 3.5 기반.
- **제작 방식**: Geometry Nodes를 활용하여 처음부터(From Scratch) 프로시저털 털(Procedural Fur)을 구현하는 과정을 다룸.
- **주요 구성 요소**:
    - **Material Assets**: 털 제작 시 머티리얼 에셋을 커스터마이징(Customizing)하는 방법이 포함됨.
- **관련 학습 분야**: 해당 교육은 Geometry Nodes 외에도 Animation, Lighting, Rendering, Rigging, Shading 등을 카테고리로 포함하고 있음.
